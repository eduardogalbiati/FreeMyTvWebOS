# Background media

Drop the morning background video here as `morning.mp4`.

- Used by the **Morning Nature** theme (05:00 - 11:59 in Auto mode, or when
  forced in Customize > Theme Mode).
- Recommended: 1920x1080 H.264 MP4, 20-60 s seamless loop, no audio track,
  ~5-15 MB so the .ipk stays small. Forest, sea and open landscapes work best.
- Free sources with permissive licenses: Pexels Videos, Pixabay, Coverr.
- You can also point the app at a URL instead of a packaged file in
  Customize > "Morning Video (path or URL)". Remote files are re-streamed
  every morning; a packaged file plays offline.

If the file is missing the theme falls back to a forest/sea gradient.
